# 👩🏻‍💻 Carlos Eduardo Medeiros

**`Software Engineering Student | Tech History Enthusiast`**

Minha jornada na tecnologia não começou com código, mas com uma história. Tudo mudou quando assisti à trajetória de **Steve Jobs**; ali, percebi que a tecnologia é a interseção entre a arte e a engenharia. Foi esse "estalo" que me fez decidir o que eu queria para o meu futuro.

Concluí o ensino médio em uma **Politécnica (EAD)** e, hoje, estou mergulhado na faculdade de **Engenharia de Software**. Sou fascinado pela evolução histórica da computação — desde os garagistas do Vale do Silício até as arquiteturas modernas de software. Busco não apenas *buildar* sistemas, mas entender o propósito e a herança histórica por trás de cada inovação.
